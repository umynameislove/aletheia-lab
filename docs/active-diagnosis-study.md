# Actual evidence acquisition and bounded ML repair

This local study connects current-state measurements, finite diagnosis and
executed restoration branches. It is separate from frozen single-turn diagnosis
variants, historical evaluation labels and registered main attempts. It does
not grant a product consumer authority to modify a deployed model.

## What the controller observes

An initial prediction loss and reference loss establish the declared consequence
gate. The controller then receives actual input/model/training comparisons or
results of isolated restoration branches. Fixture names, source/seed IDs,
intervention truth, evaluator references and realized case tables are not
included in the controller payload. The declared hypothesis/response model,
including each hypothesis's expected action outcomes, is visible to all selectors.
The local model also receives the same
measured action-cost estimates as the ordinary selectors.

The six caller-owned actions are reads of actual input, resident model and
training targets, restoration of enrolled input or resident model, and refit
from enrolled clean training data. A branch always starts from the original
faulted snapshot. It does not silently compound previous trial repairs.
Only allowlisted actions execute; strings in model output cannot choose files,
network destinations, Python expressions or shell commands.

Every actual operation has a minimal receipt and a separate recorded proof.
The proof is captured from that same execution, not a second uncharged replay.
It retains measured state hashes, buffer footprints, prediction/fit counts,
and functional versus intended-state restoration. Hashes do not remove the
trusted-host/hook assumption. Byte footprints are not total solver traffic.

## Comparators and resource accounting

Static evidence, sufficient full ordinary capture, cheap-first, information
gain/cost and finite equivalence-class edge cutting use the same executor,
capabilities, time envelope and total call cap. Full ordinary capture collects
all available state reads; if none exist, it collects the restoration probes.
All arms subsequently execute a selected repair, or a common recovery decision,
when supported and affordable. An ambiguous origin can still permit functional
recovery without proving intended-state restoration.

Action reservation costs are twice the p95 of actual development measurements,
fixed before transfer. Tight and relaxed budgets are author-defined sensitivity
envelopes, not operator SLOs. Selection, failed work, final decision and repair
are charged to the complete episode clock. Timers for nested native operations
are not added again to total wall time. Enrollment/fit setup is reported once
per native world separately; these measurements are not serving-latency overhead.

An optional separately qualified local proposer sends only the allowed finite
payload to a caller-owned loopback server. LLM-only takes its first proposal;
hybrid applies EC² to the proposed subset. This is finite action selection,
not unrestricted discovery of hypotheses/probes or a new active-learning method.
Raw responses, cold model loading and operational failures stay in private
execution evidence. Synthetic transport qualification is not diagnosis efficacy.

## Interpretation

Report separately:

- identification relative to the declared finite catalogue;
- exact hidden-mechanism match and catalogue-specificity failures;
- functional recovery and enrolled-state recovery;
- deadline/resource completion and missing/failed operations;
- acquisition, planning, repair and setup resources.

Coarse measurements can alias excluded operators. Matching one advertised row
does not prove that no other mechanism exists. Successful sign compensation can
restore output at the wrong boundary; it is not automatically correct diagnosis
or correct state repair. No classifier/judge score substitutes for these gates.

Development uses exposed Iris data. Controlled transfer uses bundled breast
cancer data, with five overlapping splits and eight authored conditions; 800
policy opportunities are nested within 40 native worlds on one dataset, not
800 independent incidents. Excluded operators were engineering-exposed on Iris:
the transfer is not mechanism-blind or a natural deployment study. The bundled
data are small, not evidence of production-scale efficiency.

## Reproduce

From the checkout with the project environment and `PYTHONPATH=src`, run
`scripts/active_diagnosis_study.py`. All destinations must be new files outside
the repository; earlier attempts are not overwritten.

1. `calibrate --output <costs.json>` measures the exposed development operations.
2. `development --calibration <costs.json> --output <development.json>` executes
   the development census.
3. `design --calibration <costs.json> --output <design.json>` binds the final
   design, source files and cost artifact before new transfer outcomes.
4. `transfer --calibration <costs.json> --design <design.json> --output <transfer.json>`
   rejects changed design/code/cost identity before execution.
5. `analyze --input <transfer.json> --expected-input-sha256 <trusted-byte-pin> --output <analysis.json>` rebuilds the saved
   aggregates without remeasuring clocks or rerunning native executions.

Use a byte pin from the trusted execution record, not one computed from an
unchecked candidate. Replay checks the full opportunity/world census, retained
proof projections, catalogue compatibility, repair grades and recorded timing
accounting before accepting an aggregate. Hashes and consistency checks do not
authenticate the host or independently reconstruct numerical state.
Inputs are bounded regular JSON objects; duplicate members, nonfinite numbers
and symlink aliases are rejected. Outputs are create-only outside the checkout,
including on long Windows paths. CLI failures return a safe error type without
private input paths or traceback. Native execution is never a replay fallback.

The packaging correction counts only actual native attempts, including failed
final repairs; selector failures are not native probe calls. Retained executions
had neither affected failure type, so their measured counts remain unchanged.
Their original code bindings remain historical, not silently replaced by current
source hashes. Future executions require new cost/design bindings for current code.

The evaluation test profile includes policy, local transport and native
closed-loop regressions. Native Windows, remote CI and real API/dashboard
integration require their actual environments; local tests cannot establish them.

## Measured local result and disposition

The ordinary execution completed 200 development opportunities on ten Iris
worlds and 800 controlled transfer opportunities on 40 breast-cancer worlds.
These are dependent policies/views/envelopes, not independent incident counts.
All excluded operators were engineering-exposed on Iris before transfer.

At the relaxed one-second envelope, each row below covers the same 40 worlds.
Supported identification counts only exact in-catalogue matches. An excluded
operator alias is a specificity failure of a finite classification shortcut,
not an unrestricted claim emitted by the guarded runtime or by the model.

| Capability | Policy | Supported known / excluded alias | Functional / state recovery | Calls | Median episode ms |
| --- | --- | ---: | ---: | ---: | ---: |
| All | Full | 25 / 15 | 30 / 30 | 150 | 2.485 |
| All | IG | 25 / 15 | 30 / 30 | 95 | 2.360 |
| All | EC² | 25 / 15 | 30 / 30 | 95 | 2.440 |
| Restoration only | Full | 15 / 5 | 30 / 25 | 150 | 11.492 |
| Restoration only | IG | 15 / 5 | 30 / 25 | 70 | 4.291 |
| Restoration only | EC² | 15 / 5 | 30 / 25 | 70 | 4.240 |

Static observation identifies no singleton and runs no final repair. In the
restoration-only stratum, 20 worlds remain ambiguous even though a common
functional recovery can run. Five target-rotation worlds regain prediction
behavior after model replacement while their training lineage remains changed.
Ten transfer wrong-boundary sign compensation controls likewise recover function
without restoring intended state. Nonharmful cancellation receives no final
repair; this harm-gated policy does not establish that such state is compliant.

IG/EC² reduce calls by 36.67% with reads and 53.33% without reads compared with
full, with matched outcomes. They are existing methods, not new algorithms.
Paired EC²-minus-full warm time with reads has median -0.145 ms and range
[-0.679,+0.386] ms: no uniform latency win. Without reads the paired median is
-7.288 ms, range [-8.555,-6.088] ms. These are finite recorded local comparisons,
not population confidence intervals, serving overhead or global optima.

The development-calibrated tight envelope is one millisecond. All cheap state
reads fit the reservations, but final repair does not; restoration-only admits
no probe. Timely abstention is not fulfilled recovery. Action reservations are
measured estimates and the authoritative deadline remains actual elapsed time.

A separately qualified local 27B Q8 model ran the fixed exposed-Iris development
comparison: 32 planned slots, 29 executed, 24 actual requests including two
transport checks. Thirteen of 16 LLM/hybrid slots executed; three retained slots
were unexecuted at the global request cap. Every executed model slot matched its
full/EC² diagnosis and recovery grade. Warm medians were 8.167 seconds for the
LLM proposer and 11.808 seconds for hybrid; ordinary medians were about 0.003
seconds. Fixed ordering and machine/cache state limit speed inference. Cold
startup of 8.924 seconds and sampled server peak of 29.695 GiB are separate,
not omitted costs. This is finite action-proposal development, not open-world
discovery, matched complete-census efficacy or held-out model validation.

Independent numerical reconstruction matched every retained ordinary and model
proof with maximum loss discrepancy 0.0, using independently fit models and
direct numerical prediction/loss calculations. Shared fitting/numerical
libraries and host observation remain limitations. Saved clocks can be checked
algebraically, not remeasured retrospectively. Replay adds no validation N.

The retained conclusion is an executed, controlled evidence/repair/cost boundary.
No new-method superiority is admitted, and held-out LLM efficacy is not measured.
The current model direction stops because ordinary evidence is sufficient and
cheap for the declared catalogue, not because every open-world task was solved.
Product integration remains a separate pending consumer gate.

## Closest mechanisms

[EC²](https://arxiv.org/html/1010.3091) supplies the finite edge-cutting objective
under an explicit response/prior model; its approximation guarantees do not
automatically apply to this hard-budget/misspecified experiment. Plain entropy
gain is not the same algorithm. [RCAgent](https://arxiv.org/html/2310.16340v3)
already connects local LLM decisions with executed information-gathering tools.
[OpenRCA 2.0](https://arxiv.org/html/2606.27154v1) is a related 2026 preprint on
outcome versus causal-process evaluation. Neither supports a novelty claim for
generic tool use, a proof of cause from repair success, or efficacy in this study.
