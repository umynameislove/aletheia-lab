# Curated reproducibility reports

This directory contains small, reviewed receipts and result locks that support
publicly documented repository behavior. Each committed artifact must be
content-addressed, reproducible from a named command or protocol, and free of
credentials, private paths, raw human-study records and local experiment logs.

Large generated outputs, figures, tables and private evaluation material remain
local under the repository ignore policy. A report is not a scientific claim by
itself; public wording remains governed by the claim registry and its evidence
state.
