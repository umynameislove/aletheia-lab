# Serving recovery research scripts

See [the study and local-use instructions](../../docs/serving-recovery-study.md).

- `prepare_native.py`: create-only editions, local environment and source pins.
- `native_sequence.py`: qualified HTTP lifecycle sequence and separate reference.
- `runtime.py.in`: authored runtime template; never imported as repository code.
- `native_guard.py`: bounded owned-process and exact listener checks on macOS.
- `project_trace.py`: explicit nested allowlist for observed response fields.
- `sqlite_trace.py`: three ordinary layouts, writer kill and fresh-process recovery.

Preparations and execution outputs belong outside this checkout. These scripts
are opt-in research tools and are not part of the dashboard's repair authority.
