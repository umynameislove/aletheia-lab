ĐỌC TRƯỚC

và lưu cả kết quả thành công lẫn thất bại. Mục tiêu là kiểm bản Kiên hiện tại
trên Windows native và PostgreSQL 16 trong Docker, rồi trả evidence về cho
Kiên kiểm. Mỗi phase là một nhóm test; runner là file run_windows_tests.py
chạy nhóm đó và lưu evidence. Không cần tài khoản IdP hay mở giao diện app
thật để chạy bộ này.

Bộ chuyển giao có:
- Windows-Docker-K08-K12-20261112.zip: gói test nguyên bản, đã chốt checksum.
- 01-Huong-dan-day-du.txt: tài liệu đang đọc, là hướng dẫn chính cho người mới.

- 03-Tin-nhan-nho-chay.txt: nội dung owner có thể chuyển cho người thực hiện.

Gói test bên trong đã đủ 2.396 file nguồn, 639 file runtime, wheel và công cụ.
Không cần Git clone, ghép delta, ZIP bàn giao cũ, Node.js hoặc npm. Phần frontend
trong source là input của snapshot API, không dùng để nghiệm thu bản Quân mới.

Máy đích: Windows 11 x64 còn được Docker hỗ trợ, CPU Intel/AMD x64; WSL2,
virtualization và Docker Desktop chạy Linux containers. Docker nêu RAM tối
thiểu 8 GB. Chuẩn bị ổ đĩa có chỗ cho venv, Docker image và dữ liệu thử; mốc
